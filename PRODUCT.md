# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People checking whether a browser, proxy, VPN, or network route is using the
expected public exit. They need to compare domestic and external egress,
inspect IP reputation, and continue into focused network, browser, AI, and
service-status diagnostics.

## Product Purpose

One Ping provides one place to inspect public IP identity, routing differences,
network reachability, DNS/CDN behavior, browser exposure, AI access, and public
service status. Success means the current network state is understandable at a
glance and deeper checks remain one action away.

## Positioning

Unlike a single-source IP lookup, One Ping compares the browser's observed
network exits and connects those results to practical diagnostic tools without
inventing an overall account-safety verdict.

## Operating Context

The product is used repeatedly while changing networks, proxies, routes, or
browser settings. Results may differ by data source, Cloudflare edge, browser
capability, and third-party availability.

## Capabilities and Constraints

- Preserve every existing route and the Cloudflare Worker API contract.
- Keep Chinese and English localization, light and dark themes, mobile access,
  privacy masking, query history, and accessibility behavior.
- Display only live or explicitly unavailable results; do not ship simulated
  IPs, latency, unlock status, security verdicts, or unsupported claims.
- Cloudflare Workers with Static Assets is the production runtime.
- Third-party rate limits and browser cross-origin behavior can affect results.

## Product Principles

- Live evidence over confident decoration.
- Comparison before conclusion.
- Dense enough for repeated operation, clear enough for first use.
- Preserve privacy controls and expose uncertainty honestly.
- Brand personality lives in precise details, not in novelty that obscures data.

## Accessibility & Inclusion

Keyboard access, visible focus, reduced-motion support, WCAG AA contrast, and
stable responsive layouts are required across all diagnostic workflows.
